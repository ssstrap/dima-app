# дима в курсе — приложение

Тексты для TikTok на каждый день, рекламные треки, посты и сторис для Telegram.

## Как выложить на GitHub (один раз)

1. Зайди на github.com → справа сверху **+** → **New repository**.
2. Имя: `dima-app`. Оставь **Public** (бесплатный GitHub Pages работает только с публичными). Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Перетащи **все файлы из папки** `kurs/dima-app` (не саму папку). Внизу **Commit changes**.
5. **Settings** → слева **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сверху появится ссылка вида `https://твой-ник.github.io/dima-app/`.

## На телефон как приложение

- **iPhone (Safari):** открой ссылку → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открой ссылку → ⋮ → «Добавить на главный экран».

## Как обновлять тексты

Claude собирает новые тексты командой `node data/build_app.js` (из папки kurs). Меняются два файла: `data.js` и `index.html`.
В репозитории: **Add file** → **Upload files** → перетащи эти два файла → **Commit changes**. Через минуту на телефоне потяни страницу вниз, чтобы обновить.

## Что где

- **TikTok:** день → 10 текстов. Кнопка «скопировать текст» берёт текст на экран, «подпись» — подпись с хештегами, ✓ — «выложил». Внизу карточки — какой звук ставить. Время по Москве и по Астане.
- **Реклама:** тексты под рекламные треки, фильтр по настроению трека. Охваты тут не ждём.
- **Telegram:** посты основы по дням (20:00 МСК), личный канал, сторис. Всё в [скобках] — заменить своим.

Отметки «выложил» и «скопировано» хранятся только в этом телефоне.
Сайт закрыт от поисковиков, но репозиторий публичный: по прямой ссылке его может открыть любой.
